# Changelog

## 0.7.0 - 2026-11-02
- Finance committee meets monthly (unit standard; CAPR 173-1 sets quarterly).
- Heavier rule between each week's tasks.
- VTWG 173-1 supplement deadlines added to event deadlines: card receipts
  7 days, lost-receipt letter 48 hrs, travel report 7 days.

## 0.6.0 - 2026-11-02
- Weekly items are separate sign-offs for W1–W4. Rows run week by week;
  dated items sit after the week their date falls in; monthly items last.
- Added the unit's weekly vehicle inspection (unit standard).
- Save PDF button; sheets go to the unit file share. OPR column moved
  after Due.

## 0.5.0 - 2026-11-02
- Self-SUI due Jan 27, 2027; SUI due Jan 27, 2028 (charter Jan 27, 2026).
- SUI area shown on each task row; area header rows removed.
- Second KPI row: FY2027 percent complete by SUI area.
- Checkbox replaced by a row number; a CAPID marks the task done. CAPID
  field shaded, no underline. Month heading shows only in print or in
  All months.

## 0.4.0 - 2026-11-02
- Members enter only their CAPID on each finished task; the box fills and
  today's date stamps. Nothing is saved; the record is the PDF they email.
- Each printed month carries a coded record line; "Load completed sheets"
  reads emailed PDFs back and updates the tiles. Read in the browser only.
- Warns before closing with unsaved entries; PDF file name is set
  automatically (FY27-MM-MON_OPR_date).

## 0.3.0 - 2026-11-02
- Renamed Unit Operations Checklist; header cut to unit and FY lines.
- Month and officer pickers; opens on the current month.
- KPI tiles: month, quarter and FY percent complete (from recorded
  completions) and the next SUI action.
- Tasks grouped by SUI inspection area; Reference and Done columns
  removed (references moved to Sources and process).

## 0.2.0 - 2026-11-02
- Adds the locked validation process to the header: date and initials,
  eServices record or one file in SUI Evidence by area, CC signs the month.

## 0.1.0 - 2026-11-02
- First draft for review: FY27 month list (Oct–Sep), officer filter, event
  deadlines, SUI cycle for VT-014 (chartered Jan 2026), sources and
  applicable NER/VTWG supplements. Prints to letter paper.
