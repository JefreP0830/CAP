# Changelog

## 2.4.0 - 2026-11-24

- Finish this cadet button on each card: checks that cadet, lists what is still needed, and folds the card into a summary line (name, CAPID, flight, duty, overall) with Edit and Remove.
- Submit and Add another cadet appear only when every cadet is finished; Submit comes first and names the count.
- How to use updated for score, finish, add or submit.

## 2.3.0 - 2026-11-24

- One-line definition under each category title (13px gray), also in the rubric table.

## 2.2.0 - 2026-11-24

- Removed the optional Cadet Full Track Report upload; cadets enter CAPID and last name directly.
- "Add cadet" renamed "Add another cadet", with a one-line note on what it does.
- Share fallback spelled out: Share and Save to this device buttons; every failure path tells the evaluator to attach the saved PDF to an email to the cadet commander.

## 2.1.0 - 2026-11-24

- Working tabs numbered and shaded as steps: 1. Score, 2. Tally, 3. Select; they stay on one row on phones. How to use refers to the numbered steps.

## 2.0.0 - 2026-11-24

- Score tab: evaluator CAPID, last name and cadet command team role; period is a from/to date range defaulting to the current two-month block.
- Cadet rows: CAPID, last name, flight, duty position; flight carries to the next cadet; optional Cadet Full Track Report fills last name from CAPID and back.
- Overall score out of 15 on every cadet; Why and Why Not observations (3 needs Why, 1 needs Why Not).
- Submit validates the sheet and produces a PDF sent through the share menu, like the Drill Evaluator; replaces copy and paste.
- Tally reads scores straight out of the submitted PDFs; flags ties, incomplete scores and mixed periods.
- Select preselects the top cadet, drafts the reason from Why observations, and saves a selection record PDF.
- "Remove" renamed "Remove this cadet" and shown only when there is more than one cadet.

## 1.0.0 - 2026-11-24

- First draft for review: How to use, Score, Tally, Select, and Rubric and rules tabs.
- Five-category, 1-3 rubric with a behavior anchor for each score; observed example required for any 1 or 3.
- Evaluators copy scores as a text block; command staff pastes blocks to tally.
- Persists nothing (D-004); warns before leaving with scores entered.
