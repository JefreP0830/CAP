# ES & FEMA Test Guides

Quick companion sheets for students taking these online tests:

| Sheet | Test | Where |
|---|---|---|
| FEMA SID | Register for a FEMA Student ID and log in the first time | cdp.dhs.gov/femasid |
| CAPT 116 | General Emergency Services (CAPR 60-3) | CAP eServices |
| CAPT 117 | ES Continuing Education, Parts 1 to 3 | CAP eServices |
| IS-100 | Introduction to ICS (IS-100.c) | training.fema.gov/is |
| IS-200 | Basic ICS for Initial Response (IS-200.c) | training.fema.gov/is |
| IS-700 | Introduction to NIMS (IS-700.b) | training.fema.gov/is |
| IS-800 | National Response Framework (IS-800.d) | training.fema.gov/is |

Each sheet has a few core essentials with diagrams, then every test question
with only its correct answer. Questions are verbatim from the tests; do not
reword them.

Use: open a sheet from the top bar (each has its own link, e.g. `#is100`),
then **Print this sheet** for letter paper, or **Print all**. The search box
filters the answer key on screen.

## Editing

`index.html` is generated. Edit `build/questions.py` (questions and answers)
or `build/build.py` (essentials, diagrams), then run `python3 build/build.py`.
Styles and script live in `build/template.html`.
