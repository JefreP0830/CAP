# OCP Uniform Worksheet (VT-014)

One printed page that cadets fill in to check their own OCP uniform and cold-weather gear,
or to check each other's. They mark Y or N for each item and write a measurement for anything they
need. The supply officer uses the returned sheets to build the order.

**Use:** open the page and press **Print** (Letter, 100% / Actual size). The Print button and
top bar do not print.

## Sections

| Section | Items |
|---|---|
| Head | Utility cap, Duty cap (watch cap) |
| Upper body | T-shirt (Tan 499), Shirt, Fleece jacket; Name tapes (x3), CIVIL AIR PATROL tape, US flag, Squadron patch, CAP AUX tab, Wing patch, Grade insignia (x2) |
| Lower body | Pants, Belt |
| Hands and feet | Gloves, Boot socks, Boots |

## Files

- `index.html`: the worksheet, self-contained (font embedded, nothing loaded from the web, nothing saved).
- `build.py`: rebuilds `index.html` (`python build.py`).
- `fonts/`: Rajdhani SemiBold, copyright 2014 Indian Type Foundry, SIL Open Font License 1.1
  (https://openfontlicense.org). The copyright and license link are carried in the font file itself.

The sheet holds no member data. Completed paper sheets stay with the supply officer.
