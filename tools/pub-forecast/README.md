# CAP Rule Changes (Vermont Wing)

One page, updated monthly, that tells members in plain words:

1. **Changed this month**: official CAP publication changes posted this month (ICLs, regulations, pamphlets).
2. **Changed last month**: a short recap so nothing is missed.
3. **May change next**: forecasts, marked *Likely* or *Possible*, each with the evidence behind it.
   A forecast never states new rule text as fact.

Written for readers aged 55-70 at a 3rd-6th grade reading level: 20px text, black body text,
one change per card, three questions per card (what changed, who it touches, what Vermont should do),
and a link to the official letter. Dates set by a regulation print in red.

## Monthly update

Edit only the `DATA` block at the top of the script in `index.html`:

- `now`, `last`: one object per change. Wrap any regulation date in `{braces}` to print it in red.
- `next`: `odds` is `Likely` or `Possible`; `why` lists the evidence.
- `unclear`: optional; use when the official letter conflicts with itself.

Sources checked each month are listed in the page's "How we check" section.

## Forecast signals

- ICLs piling up on one regulation (rewrite pressure)
- An ICL that says a later revision will absorb it
- The Regulations for Preview page (drafts before release)
- Age of the base regulation

## Files

- `index.html`: the page, self-contained (Rajdhani embedded, nothing saved, no member data).
- `icons/`: app icon (generic mark, not a CAP official emblem).
