# Hotwash

The ten-minute version of an AAR, run before people leave. Type three lists and the tool builds
an email you can paste into Gmail or Outlook, or open in the mail app.

## CHECK SIX

Pilots check six o'clock to see what is behind them.

| Letter | Part | Prompt |
|---|---|---|
| S | Saw | What we observed: facts, numbers, times |
| I | Insight | What we learned: why it happened, what to keep, what to change |
| X | eXecute | What we will do to improve: action, owner (duty position), due date |

Copy email puts formatted HTML and plain text on the clipboard. Nothing is saved (D-004).
Use the After Action Review (`tools/aar/`) for the full write-up.
