Cadet Promotion Tracker

Civil Air Patrol cadet promotions

Load this week's Cadet Promotions Full Track report

Drag the export onto this page, or use Load eServices exports above. Nothing is saved; closing this tab clears the roster.

In eServices

  1. Log in to eServices.
  2. Go to Menu > Cadet Programs > Cadet Promotions.
  3. Open the Cadet Promotions menu and select Reports.
  4. Under Report, select Cadet Promotions Track Report.
  5. Under Reg-Wing-Unit, select your unit.
  6. On the Cadet Promotions Full Track page, choose Search by Organization and confirm your unit is selected.
  7. Check Only Show Cadet's Current Achievement.
  8. Select Export to Excel. The file saves to your Downloads folder as Cadet_Full_Track_Report-MM_DD_YYYY. Leave it there and don't rename it: the date in the name tells the tracker which week it is, and next week's To Be Pinned list compares against it.

In this tracker

  1. Select Load eServices exports.
  2. In your Downloads folder, select this week's and last week's Cadet_Full_Track_Report files together (hold Ctrl and click both). This week's file alone also works, without the To Be Pinned list.
  3. The roster loads. Click a summary tile to filter it.
  4. Print: Print this view (roster for the wall), Print weekly report (pin, tests, ready), or pick a cadet and Print report card.
  5. Each week, repeat with the new export.
